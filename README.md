

\# Student Management System



\## Project Description

This is a simple Student Management System developed using Python.



It helps users manage student information through a menu-driven application.



\## Features

\- Add Student Details

\- View All Students

\- Search Student by ID

\- Exit the Application



\## Technologies Used

\- Python

\- Object-Oriented Programming (OOP)

\- Classes and Objects

\- Lists and Dictionaries

\- While Loop

\- Conditional Statements



\## How to Run the Project



1\. Install Python.

2\. Download this repository.

3\. Open the project folder in CMD.

4\. Execute:



&#x20;  python main.py
